iPhone Zkratky

Volitelný přístup k provizním souhrnům z vlastního telefonu.

Načítám nastavení…
Secret nikdy nevkládejte do URL ani nesdílejte. Po regeneraci stará Zkratka přestane fungovat.

Nasazení

Apps Script → Nasadit → Nové nasazení → Webová aplikace.
Spustit jako: já. Přístup: kdokoli (včetně nepřihlášených).
Zkopírujte URL končící /exec. Zkratka odešle secret v POST JSON; gateway je pro jiné požadavky uzavřená.

Apple Zkratka

Akce Získat obsah URL: metoda POST, tělo JSON, pole secret = hodnota výše. Výsledek je JSON slovník; získejte klíč notification a použijte jej v akci Zobrazit oznámení. Zobrazujte jen při ok=true.

JSON proměnné

totalCommission, yesterdayCommission, todayCommission, totalDocuments, yesterdayDocuments, todayDocuments, lastSync, lastSyncTime, lastClosureDate, daysSinceLastClosure, currency, notification.

Záporné dobropisy jsou započtené. Hodnoty vycházejí z posledního dokončeného importu. Více měn: použijte pole currencies; rozdílné měny se nesčítají.
